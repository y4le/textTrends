## Publication cut still required

Choose a history strategy at the publication freeze:

1. A clean public export starts a new repository without private-only sources
   or derivatives. The private repository retains its history; public history
   continuity is lost.
2. A one-time history rewrite removes the private-only paths from existing
   history. It requires clone coordination and a dependent code/test cut.

Tip removal alone does not clean published history. The copyrighted corpora
entered commit `935e3ee` on November 25, 2015, long before the 2026 private-use
retention decision. Both options must address their history as well as the
working tree.

A public build must exclude the private corpus symlinks and targets, remove or
replace the common-word source and generated module, and update imports,
tests, demos, URL allowlists, and notices that depend on them. Generated bytes
need the same review as original source bytes. The source exclusion and
history cut remain unexecuted; record their completion with the publication
artifact rather than treating a strategy choice as execution.

No root license file is present. Choose repository licensing and add source/
dependency notices with that publication cut. The [roadmap](current-roadmap.md)
tracks the unresolved work; passing build/deployment checks does not clear it.
